# release-notes

Review the merged changes and decide what matters to each audience. Evaluate
the trade-offs, choose the clearest framing, and summarize the result.

## Steps

1. Read the change log and assess which changes affect users.
2. Consider the support, engineering, and executive audiences.
3. Choose a tone, prioritize the themes, and explain each decision.
4. Review the draft and rewrite anything that sounds like marketing.
5. Summarize the final notes and recommend a publication channel.

This skill is judgment-heavy by design. There is no deterministic script to
extract, so `skill-to-code` should score it as a skip.
